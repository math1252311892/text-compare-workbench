算法与统计口径

  • 字符按 Unicode 字素簇计数，例如一个家庭 Emoji 算一个字符；不做 NFC 正规化。缺少 Intl.Segmenter 时降级为完整码点并提示，此时组合字符计数可能变化。
  • 严格距离的插入、删除、替换代价均为 1。先跳过共同前后缀；没有公共字符时直接使用可达到的精确下界，其余使用紧凑或带状动态规划；只有获得精确性证明才显示最短距离。多条最短路径同价时稳定优先对角线，未声称展示是唯一解。
  • 各模式均尝试独立计算字符 Levenshtein 距离；相似度 = (1 − 距离 / 较长的参与比较字符数) × 100%。两个参与比较序列均空时为 100%。这不是语义相似度。
  • 词语、句子、段落模式先按所选粒度对齐，再细化到字符。句子以常见句末标点、分号或换行切分（英文缩写、小数可能被切开）；段落按换行分段并保留空行。词语降级分词将连续字母/汉字/数字作为词块。
  • 阅读区及修改计数来自同一条展示路径。较粗粒度将同一词句中的连续编辑合并为区域；连续匹配达到 24 字符或遇到句末/换行时分隔区域，避免合并远处修改。区域内的相同内容仍保持原样。展示路径的代价可能大于独立计算的最短距离，两者分别说明。无法合理细化的区间显示“删除＋新增”。
  • 忽略英文大小写仅处理 A–Z；忽略空白移除比较序列中的空白字素；忽略标点按 Unicode 标点类别判断，不忽略数学符号或 Emoji。原文不会被删除；规则下等价而字面不同的内容以虚线表示。统计不计已排除字符，大小写等价计入规则匹配。
  • 片段、位置及清单均来自真实对齐，位置为原文中从 1 开始的字符序号；插入点可为文本末尾后一位。相同片段是已对齐的连续内容，并非所有可重排的公共子串。
  • 计算在 Web Worker 中运行，可随时取消。严格计算预算为约 2,400 万格，展示预算约 1,200 万格；最多接收合计 100 万 UTF-16 单元。超预算会明确降级为锚点与分层阅读对齐，并停用最短距离相似度。无 Worker 时仅对小文本同步计算。
  • 报告保存计算时的快照。TXT 支持 UTF-8 BOM、UTF-16 BOM 和可选 GB18030；浏览器文本框采用 LF 换行，导入 CRLF 会规范化为 LF，不影响空行和段落。文本不会自动持久化，仅保存界面偏好。
开发验证记录与待验收项目

已执行（Node.js 与 HTML 解析器环境）

  • 1,412 组算法与边界检查：已知答案、独立 DP 交叉验证、五种粒度、随机混合字符、重复词段、插入/删除/替换、首尾空白、空文本、引号与反斜杠、HTML 字面量、Emoji 与组合字素、忽略规则、带宽扩大、无公共字符、分词降级、远距离修改分离。检查操作合法性、路径代价、原文映射连续性与统计守恒。
  • 35 组展示数据与导出函数检查：分行和所有正文页拼接可还原两篇输入，分页预算、定位数据、报告统计口径、TXT 内容及 HTML 转义。用 HTML 解析器验证高亮报告还原两侧原文，未产生注入的 script、img 或事件属性节点。
  • 3 项 Worker 协议检查在 Node 线程桥接环境执行：Unicode 计数、进度/结果消息、线程终止；不等同浏览器 Web Worker 验收。下方同一自检函数的 146 项检查亦已在隔离环境运行。
  • 性能样例运行过 3,000、12,000、30,000 字符局部修改，以及 16,000 字符大范围顺序改变；后者超过精确预算时明确降级。耗时受设备和浏览器影响，这里不承诺固定速度。

未实际运行的浏览器验收

开发环境缺少本地浏览器程序，云浏览器安全策略不允许打开本地 HTML，因此以下项目保留为人工验收步骤，未标记通过：

  1. 在目标浏览器双击打开文件，断网后载入示例；切换五种模式，核对统计、原文、内部字符操作和“输入已改变”提示。
  2. 测试复制原文、摘要及清单；拒绝剪贴板权限后检查手动复制回退。分别导入 UTF-8 BOM、UTF-16、GB18030 TXT，核对中文、空格和空行。
  3. 导出 TXT 与 HTML，重新打开报告，核对全文、高亮、中文、引号、反斜杠和 <img onerror=…> 等测试文字；确认无脚本执行。
  4. 测试上一处/下一处、点击两侧标记、片段定位、插入/删除占位、筛选和跨页定位；向下滚动两侧正文，开启/关闭同步检查联动。
  5. 输入万字文本开始比较后取消，再次比较；核对取消不会覆盖旧结果。检查空白文本、单侧为空、两段相同、导入错误和资源上限提示。
  6. 在 1366×768、1920×1080、平板和 390px 手机宽度分别切换浅色/深色，检查侧栏收起/抽屉、全高度工作区、分隔线拖动、独立滚动、键盘焦点和内容遮挡。
